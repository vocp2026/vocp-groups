## บทบาทและรหัสเข้าใช้งาน

เปิดเว็บแล้วเห็นตารางรายชื่อทั้งหมดได้ทันทีโดยไม่ต้องใส่รหัส (ไม่แสดงรหัสนิสิต) — ปิดได้ด้วย `PUBLIC_VIEW = false` ใน `Code.gs`
ปุ่ม **เข้าสู่ระบบ** มุมขวาบน · ช่องใส่รหัสมีปุ่ม 👁 กดเพื่อแสดง/ซ่อนรหัส

| บทบาท | รหัส | เก็บไว้ที่ | สิทธิ์ (ค่าเริ่มต้น) |
| --- | --- | --- | --- |
| นิสิต | ช่วงแรก: **เลขที่** เช่น `01-043` · เมื่อผู้ดูแลกรอกรหัสนิสิต 10 หลักแล้ว: ใช้ **รหัสนิสิต** และเลขที่เดิมจะใช้ไม่ได้อีก | คอลัมน์ "เลขที่" / "รหัสนิสิต" ในแผ่นงานรายชื่อ | เห็นเฉพาะกลุ่มของตัวเอง (แถวของตัวเองไฮไลต์) — แก้ไขไม่ได้ |
| อาจารย์ผู้สอน | ตัวเลข 4 หลัก เช่น `6901` | แผ่นงาน "ผู้ใช้ (อาจารย์-TA)" | ดูทั้งหมด · ย้ายกลุ่ม · แก้สถานะ กลุ่มอาชีพ ประสบการณ์ อาชีพ |
| TA ผู้ช่วย | `TA` + 4 หลัก เช่น `TA6901` | แผ่นงาน "ผู้ใช้ (อาจารย์-TA)" | ดูทั้งหมด · ย้ายกลุ่ม |
| ผู้ดูแลระบบ | รหัสผ่านผู้ดูแล | Script Properties (`ADMIN_PASSWORD`) | **ทุกอย่าง**: เพิ่ม/ลบ/แก้ไขนักศึกษาทุกช่อง (รวมเลขที่และรหัสนิสิต), เพิ่ม/เปลี่ยนชื่อ/เรียงลำดับ/ลบกลุ่ม, จัดการอาจารย์และ TA, แก้ชื่อระบบ หัวคอลัมน์ และตัวเลือก dropdown ทั้งหมด |

- สิทธิ์ปรับได้ที่ค่าคงที่ `PERMS` ใน `Code.gs`
- ตรวจสิทธิ์ที่ฝั่ง Apps Script ทุกคำขอ นิสิตจึงดึงข้อมูลคนอื่นนอกกลุ่มไม่ได้แม้จะแก้โค้ดหน้าเว็บ
- อยู่ในระบบได้ 6 ชั่วโมง (หรือจนปิดแท็บ) · ใส่รหัสผิด 5 ครั้งจะล็อกรหัสนั้น 15 นาที และถ้าทั้งระบบผิดเกิน 50 ครั้งใน 10 นาที จะปิดการเข้าสู่ระบบชั่วคราว
- ถ้าลบอาจารย์/TA หรือลบรหัสนิสิต คนนั้นจะถูกออกจากระบบทันทีในคำขอถัดไป

> ⚠️ รหัส 4 หลักมีเพียง 10,000 แบบจึงเดาได้ง่ายกว่ารหัสผ่านทั่วไป ระบบล็อกช่วยชะลอการเดา แต่อย่าใช้เก็บข้อมูลที่อ่อนไหวมาก

## ขั้นที่ 1 — Google Sheet + Apps Script

1. สร้าง Google Sheet ใหม่ที่ <https://sheets.new>
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. วางเนื้อหา `apps-script/Code.gs` แทนโค้ดเดิมใน `Code.gs`
4. กด **+ → Script** ตั้งชื่อ `Seed` แล้ววางเนื้อหา `apps-script/Seed.gs`
5. บันทึก → เลือกฟังก์ชัน **`setup`** → **Run** → อนุญาตสิทธิ์ (Advanced → Go to … → Allow)
6. ใน **Execution log** คัดลอก `API_KEY` ไว้ใช้กับ GitHub Actions
7. (แนะนำ) หลัง setup สำเร็จ ลบบรรทัด `INITIAL_ADMIN_PASSWORD` ใน `Seed.gs` ออกได้ — รหัสถูกเก็บใน Script Properties แล้ว

> **เปลี่ยนรหัสผ่านผู้ดูแล**: ในฟังก์ชัน `setAdminPassword` ใส่รหัสใหม่ใน `NEW_PASSWORD` → Run → ลบรหัสออกจากโค้ด
> หรือ Project Settings ⚙️ → Script Properties → แก้ `ADMIN_PASSWORD`
>
> **อัปเกรดจากเวอร์ชันแรก**: วาง `Code.gs` ใหม่แล้ว Run `setup` อีกครั้ง ระบบจะแทรกคอลัมน์ "รหัสนิสิต" ให้เอง โดยไม่ลบข้อมูลเดิม

## ขั้นที่ 2 — Deploy เป็น Web App

1. **Deploy → New deployment → Web app**
2. Execute as: **Me** · Who has access: **Anyone**
3. คัดลอก Web app URL (ลงท้าย `/exec`) → ทดสอบเปิด `URL?action=ping`
4. แก้โค้ดครั้งต่อไป: **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**

## ขั้นที่ 3 — GitHub

1. ใส่ URL ใน `docs/config.js`
2. Push:
   ```bash
   git init && git add . && git commit -m "Student grouping app"
   git branch -M main
   git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อ-repo>.git
   git push -u origin main
   ```
3. **Settings → Pages → Source: GitHub Actions**
4. **Settings → Secrets and variables → Actions** เพิ่ม `GAS_URL` และ `GAS_API_KEY`
5. เว็บอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

## ขั้นที่ 4 — เริ่มใช้งาน (ผู้ดูแล)

1. เข้าสู่ระบบด้วยรหัสผ่านผู้ดูแล
2. **อาจารย์ / TA** → แก้แถวตัวอย่าง `6901`, `TA6901` เป็นชื่อจริง หรือลบ แล้วเพิ่มคนอื่น
3. กด **ตาราง** → กรอก **รหัสนิสิต 10 หลัก** ของแต่ละคน (พิมพ์แล้วกด Tab บันทึกทันที) — หรือกรอกตรงใน Google Sheet ก็ได้
4. นิสิตเข้าสู่ระบบได้ทันทีเมื่อรหัสนิสิตของตนถูกกรอกแล้ว
5. **ตั้งค่าข้อความ** → แก้ชื่อระบบ คำอธิบาย ชื่อหัวคอลัมน์ และตัวเลือก dropdown · ปุ่ม ◀ ▶ ✏️ 🗑 บนการ์ด = เรียง/เปลี่ยนชื่อ/ลบกลุ่ม

ทุกการเปลี่ยนแปลงถูกบันทึกในแท็บ "บันทึกการแก้ไข" (ใคร ทำอะไร เมื่อไร ค่าเดิม → ค่าใหม่)

## API

ทุกคำขอจากหน้าเว็บ: `POST` body JSON, `Content-Type: text/plain`

| action | พารามิเตอร์ | ใครใช้ได้ |
| --- | --- | --- |
| `login` | `code` → ได้ `token` | ทุกคน |
| `list`, `logout` | `token` | ทุกบทบาท |
| `move` | `token, id, group` | อาจารย์, TA, ผู้ดูแล |
| `update` | `token, id, data` | อาจารย์ (บางช่อง), ผู้ดูแล |
| `add`, `delete` | `token, data` / `token, id` | ผู้ดูแล |
| `addGroup`, `renameGroup`, `deleteGroup`, `moveGroup`, `saveConfig`, `saveUsers`, `snapshot` | `token, …` | ผู้ดูแล |
| `snapshot`, `summary` | `key` (API key) | GitHub Actions |
