[GitHub Actions ทุกคืน] ── ping + สำรองแผ่นงาน ──▶ Apps Script

## ติดตั้ง / อัปเดต Apps Script

1. เปิด Google Sheet → ส่วนขยาย → Apps Script
2. วาง/อัปเดตไฟล์ (ชื่อไฟล์ต้องตรง): `Code.gs`, `Seed.gs`, **`Lms.gs`** (ใหม่), **`LmsSeed.gs`** (ใหม่) — กด ＋ → สคริปต์ เพื่อเพิ่มไฟล์
3. เลือกฟังก์ชัน **`setup`** → Run (ใส่ข้อมูลตั้งต้นเฉพาะแท็บที่ยังว่าง ไม่ลบของเดิม)
4. ดู **Execution log**: มีรหัสผ่านอาจารย์/TA ที่สุ่มให้ (ดู/เปลี่ยนภายหลังได้ในหน้า Admin → ทะเบียนนักศึกษา / จัดการระบบ)
5. **การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ✏️ → เวอร์ชันใหม่ → ทำให้ใช้งานได้** (URL เดิมใช้ต่อได้)
   ถ้าสร้างรายการใหม่แทน จะได้ URL ใหม่ → ต้องแก้ `docs/config.js` และ GitHub Secret `GAS_URL`

## แก้ข้อมูลใน Google Sheet โดยตรง

แต่ละแท็บ LMS มีคอลัมน์ `key`, คอลัมน์สรุปให้อ่านง่าย, `json` (ข้อมูลจริง), `updatedAt`, `updatedBy`
คอลัมน์ต่อไปนี้แก้ในชีตได้และมีผลทันที: PIN/ชื่อ/จังหวัด/อาชีพ ของนักศึกษา · username/password ของบุคลากร · ตารางเรียน · ลิงก์และหมายเหตุคลิป · คำแนะนำอาจารย์ · เวลาเช็กชื่อ
(ช่องอื่นให้แก้ผ่านหน้าเว็บ เพราะข้อมูลจริงอยู่ในคอลัมน์ `json`)

## ความปลอดภัย

- หน้าเว็บบน GitHub ไม่มีรายชื่อ ข้อมูลส่วนบุคคล หรือรหัสผ่าน — โหลดจาก Sheet หลังเข้าสู่ระบบ และเซิร์ฟเวอร์ส่งเฉพาะข้อมูลที่บทบาทนั้นมีสิทธิ์เห็น
- เซิร์ฟเวอร์ตรวจสิทธิ์ทุกการบันทึก (เช่น นักศึกษาบันทึกได้เฉพาะของตนเอง, อาจารย์แก้ได้เฉพาะช่องคำแนะนำ)
- การล้าง/รีเซ็ตข้อมูลต้องยืนยัน 2 ชั้น + รหัสผ่าน Admin และระบบสำรองแท็บเดิมเป็นแท็บซ่อน "สำรอง LMS …" ทุกครั้ง
- PIN ตั้งต้น 1234 เดาได้ง่าย — ให้นักศึกษาเปลี่ยนรหัสเมื่อเข้าครั้งแรก (ระบบเปิดหน้าเปลี่ยนรหัสให้อัตโนมัติ)
- คลิปที่กด "Upload คลิป" จากเครื่องเปิดได้เฉพาะเครื่องนั้น — ให้ใช้ลิงก์ YouTube / Google Drive เพื่อให้ทุกคนเห็น
